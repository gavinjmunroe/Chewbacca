Before a study's number goes out, recount it without each part of a composite, and ask which real groups make it mean something else.

**Why:** Caleb caught both on the church website study on 2026-11-05. "Wait some are closed on sunday bc seventh day adventists" took closed on Sunday from 75 to 60. "Bro the access one is not mission critical" took the headline from 3 of 1,023 to 24, since one rarely answered question was doing most of the cutting. Every scanner and test had passed both. The tests proved the page matched the CSV, not that the count meant what the page said.

**How to apply:** For an all-of-N number, print the count with each item removed. If one item moves it a lot, it needs its own reason to be in. For a behavior count, name who behaves that way for a good reason and read that group's rows by name. Keep a dropped item in the public data and say why in the limits.
