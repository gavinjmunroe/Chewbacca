A church list built list-first (Google Maps, then read every site) yields about 5% when
the brief needs a signal like a baptism this year. On 2026-11-02, for Travis Johnson's
Baptize the World trial, 1,357 CA churches gave 76 usable ones and 0 church plants. The
run took over two hours, and Caleb asked "Ru brute forcing this or is the intelligent
dough system doing it?". A single search of Church Center for 2026 baptism pages turned
up real CA churches right away.

How to apply: when the brief names a signal, source by the signal first. Before a full
run or a reread, run 40 rows and state the yield and the time at full size. Read every
row Jev passes before a client sees it (see the gtm-engineering skill section "Signal
first, and price the yield before scaling").
