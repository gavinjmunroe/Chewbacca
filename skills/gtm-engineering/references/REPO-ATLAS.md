# GTM repo atlas

Scavenged 2026-10-09 by six parallel GitHub searches. 705 repos, none of them already in this skill's references or `LINKS-FROM-CALEB.md` except the typesafe-ai org repos, which are listed whole on purpose. Every row was re-checked through the GitHub GraphQL API on 2026-10-09: stars and last push are real, not recalled. The machine-readable copy is [repo-atlas.json](repo-atlas.json).

How much to trust each column: `what` comes from the repo description or a README skim. `why` is a one-line judgment written by the search agent, and in the vendors/topics section it was keyword-drafted, so read it as a lead, not a review. Nothing here has been installed or run. A repo listed is a repo found, not a repo vetted. Zero-star 2025-2026 repos are often one person's weekend project.

Search gaps the agents reported: GitHub's search API rate-limited every lane, 41 of 125 outbound queries came back empty after retries (verification and bounce handling are thin), cold-email personalization returned nothing, and SAM.gov, USAspending, crt.sh, permits and business-license feeds had no useful hits.

Never live-test a sender from this list. Any send goes through `CHEWBACCA_NO_SEND=1` and `--dry-run` first, and scrapers carry the ToS note in their risk column.
