# Sources

Everything listed here was read. Videos were transcribed with `yt-transcript`
(YouTube captions; machine text, so names and jargon can be misspelled) and
the transcript was read. Written pieces were fetched and read through a page
extractor, which summarizes, so quotes from them are the extractor's
rendering of the article and are worth checking against the original before
quoting in public. Collected 2026-10-09.

Tags are what SKILL.md cites.
