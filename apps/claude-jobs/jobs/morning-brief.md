Write the owner's morning brief for today. They read it on their phone, so keep it to one screen.

Read the second-brain checkout, never memory. Start with `core/now.md` and `hot.md` if it exists, then follow the links they name for anything dated today or this week. The memory/ folder moves fastest; when it disagrees with a domain file, trust memory/.

Shape:

1. Today: anything dated today, with its time if one is written down.
2. This week: deadlines and calls in the next 7 days, soonest first, at most 6.
3. Open loops: things marked unsent, waiting on a reply, or next, at most 5.
4. One person worth a text today, and why, from what the notes say.

Plain sentences under those four numbers, no other headers, no emojis, no em dashes. Never state a date you did not read in a file, and name the file it came from in parentheses. If a section has nothing, say so in one line and move on.
