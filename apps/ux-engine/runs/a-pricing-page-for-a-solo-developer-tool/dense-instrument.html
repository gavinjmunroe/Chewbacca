FAQ
What counts as a run?

One invocation of the CLI or editor extension against a single file or diff. Batch operations count once per file processed. Background file watchers count only when a change triggers a rule. CI runs share the same daily limit as local runs.

What happens when I hit the daily run limit?

The CLI exits with code 2 and prints a clear message. No silent failures or partial runs. Unused quota does not roll over. You can add capacity via the add-on above or wait for the reset at 00:00 UTC. Team plans can set per-user sub-limits from the admin console.

Is there a free trial on Pro?

14 days, no card required. Trial limits match Pro exactly. Runs consumed during the trial do not carry over when billing starts. You can cancel before the trial ends with no charge.

Can I switch plans mid-cycle?

Upgrades take effect immediately, prorated to the day. Downgrades apply at the end of the current billing period. Annual plans can switch to monthly at renewal. Team plans billed annually can add seats mid-cycle at the daily prorated rate.

What data leaves my machine?

Hobby: nothing. Everything runs locally. Pro and Team sync rule configs and run metadata (file paths, rule IDs, pass/fail status, timestamp) to our servers. Source file contents are never uploaded, hashed, or transmitted. See the security page for the full data flow diagram.

Open source and academic pricing

Open source projects with a public license and fewer than 5 contributors get Pro free. Email a link to your repo. Academic institutions get 60% off Team. Email a .edu address or a purchase order from your institution. Both require annual renewal.

Do you offer invoicing or purchase orders?

Yes, for Team plans with 10 or more seats. Net-30 terms. Contact sales with your billing entity name and expected seat count. Monthly billing is card-only regardless of plan size.
