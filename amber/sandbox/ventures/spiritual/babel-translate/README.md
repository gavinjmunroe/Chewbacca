# Babel — Universal real-time translation

Babel is a pre-launch landing page for a universal real-time translation product. The pitch: any two humans, any two languages, right now. The page presents the problem (8 billion people separated by 7,000 languages), the product vision (zero-lag conversation translation), and a waitlist signup. Built as a minimal dark marketing page.

## Features

- Hero section with headline, value proposition, and inline waitlist form
- Email capture with instant success confirmation state
- Three-column "Why it matters" section with problem framing
- Minimal dark design with blue accent throughout

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js 18+

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

## Deploy to Vercel

Connect the GitHub repo and deploy. No environment variables required.
