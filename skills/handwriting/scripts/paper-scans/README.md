Scanned paper from ambientCG (ambientcg.com), released under CC0.

- paper001: fine white sheet. Notebook, printer and card stock.
- paper002: recycled card with fibre flecks. Postcards, kraft-ish backs.
- paper003: crumpled white. Mixed in for a note that was folded or handled.

Only the colour and OpenGL normal maps are kept. paper.py uses the colour map's
fine detail (divided by its own blur, so the scan's tint never leaks in) and
the normal map lit from the upper left.
