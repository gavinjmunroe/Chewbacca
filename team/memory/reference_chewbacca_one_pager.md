A shareable one-pager listing what Chewbacca adds on top of a bare model, in seven groups: knows your life, touches your computer, lives on your screen, never forgets a correction, checks itself with code, runs many agents without chaos, real GTM. Made 2026-10-11 for Caleb as `~/Downloads/What Chewbacca has that no LLM does.md` and `.pdf`.

Every number on it came from the repo that night (74 hooks, 272 team memory files, 27 api-anything sites, 190 skills) or the public README (505,443 messages). Recount before reusing; they move daily. It is public-safe: no Amber name ([[feedback_amber_stealth_in_public]]), no personal data.

**How to keep it one page:** `chewbacca pdf` has no layout options, so the PDF is rendered from a copy with the blank lines between bullets removed. The .md keeps blank lines for Google Docs. 33 bullets plus intro fit; 38 spilled 8 lines.

**Stale README claim found:** README says Chewbacca has "No daemon", but `bin/chewbacca-daemon` exists and runs the one Login Items row ([[feedback_one_background_item]]). The one-pager leaves that claim out; the README line still needs fixing.

**Why:** Caleb asked for "a ton of tuff things chewbs has that no LLM has on its own."
**How to apply:** update this file, not a new one, when he asks for a pitch list again. Test each line with: would stock Claude or Codex do this out of the box? If yes, cut it.
