Changelog

What changed in Sift

New checks, changes to the run viewer and the issue queue, SDK releases and fixes. Newest first.

September 30, 2026v0.14
NewRun viewer

Claim links in the run viewer

Open any graded run and the final answer now shows each claim underlined. Click one to jump to the step that supports it, or to a note saying nothing does.

  • Unsupported claims are marked in red; stale ones show both the old and the new value.
  • Keyboard: j and k move between claims, enter opens the step.
September 22, 2026v0.13.2
FixAlerts

Reopened issues alerted twice

When a closed issue came back, teams with both a channel alert and an email digest got the channel message twice. It now sends once, with the issue's history attached.

September 15, 2026v0.13
NewChecks

Repeated-call detection

Sift now flags a run that calls the same tool with the same arguments and gets the same result three times, with no new input between the calls. The flag lists the step numbers.

Runs that loop this way rarely fail outright, which is why error-rate alerts never caught them.

September 3, 2026v0.12
SDKPython 0.6TypeScript 0.6

SDK 0.6 for Python and TypeScript

  • Tool calls made inside a thread pool are now attached to the right run.
  • A new redact option drops named fields before anything leaves your process.
  • The SDK no longer blocks your agent if Sift is unreachable; events queue for up to five minutes.
August 20, 2026v0.11
ImprovementIssues

Issue history and reopen

An issue you close and that later recurs now reopens with its full history instead of arriving as a new issue. The timeline shows when it was closed, by whom, and the first run after.
