Caleb, 2026-10-10, after a night that produced a 705-repo atlas, ~100 playbook rules and 46 GTM pack skills with none of it run on Zeutara: "No point of gathering and organizing a ton of info if it isn't actually applied."

**Why:** the night's output was all inputs (lists, rules, skills) and zero changed outcomes. Zeutara still had a 2.7% bounce rate and 2 positive replies out of 64, and no rule had touched either.

**How to apply:** after gathering anything, the same session runs it on live data (for GTM: grade the real campaigns, lists and replies, cite the rule per finding) and turns the reusable part into a gate that refuses (`gtme grade` + launch-guard), not a doc section. Before proposing new research, ask what existing rule hasn't been applied yet. See [[reference_chewbacca_gtm_arsenal]], [[feedback_enforce_dont_document]], a private note.
