Dough runs without Clay by default. Clay is a tool for the steps it does better, never the
spine. Caleb, 2026-11-02 11:27pm, during the AuraPath trial: "We shouldnt be dependent on
clay! We only use clay for things that are better done in clay".

That night the whole AuraPath list was built with no Clay at all: Google Maps sourcing, the
firm's own site for the owner, treg for verified emails, and `gtme send` from Google Workspace
inboxes for sending. Earlier the same night the setup plan still said to buy a Clay workspace
and use its Sequencer, because the client's brief mentioned "the separate Clay workspace". A
client naming a tool is a requirement to understand, not a stack to adopt: what Travis needed was
separation from his own domain and agency.

How to apply: before adding Clay (or any paid platform) to a plan, name the step and say why
Dough can't do it as well. Warmup is the current honest gap (Dough has no warmup), so a
warmup-only service is fine while sending stays in Dough.
