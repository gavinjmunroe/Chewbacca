Caleb, 2026-10-11, on a guitar midterm study app built the night before the
exam: "Terrible ux bro ru serious a flat html grid? Fix chewb to never make
smth that terrible ever again." It was five tabs over grids of cards and
tables. The interface skill was named for the prompt and never loaded, so no
template was chosen and the page fell back to a dashboard of everything.

**Why:** someone cramming needs one next thing on screen, made of the thing
they are learning. A grid of reference cards is the re-reading condition the
study-guide craft warns against, styled.

**How to apply:** study, drill and rehearse requests are the Practice session
template (skills/interface/references/taxonomy.md): a short home list with
progress, then one item full screen around the object itself (the rebuild used
a drawn guitar neck lighting each note, a staff under a playhead, one play
button, a rating after each run). His verdict on that rebuild, 40 minutes after
the first one: "Wait this is a highk goated ux." `.claude/hooks/interface-first.sh` denies a
150+ line UI page Write until the interface skill is loaded, and design-gate
now renders a standalone .html from disk instead of skipping it. See
[[feedback_tasteful_editorial_is_the_new_slop]].

Exam morning, 2026-10-12: he wanted to close the tab and be "super dialed", so
the time-blocked plan for the day went onto the app's home screen (blocks with
the current one highlighted from the clock, what to drill in each, the exam at
the end). Put the day's plan inside the practice app, not only in chat, so the
tab with the agent can close.
