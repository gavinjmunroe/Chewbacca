Getting started

Sift documentation

Sift reads every run your agent makes in production, checks the final answer against what the run actually did, and groups the failures it finds by cause. This page covers setup and the handful of ideas you need to read what Sift reports.

Quickstart

  1. Create a project key. In Sift, open Settings, then Keys, and create a key for this agent. Put both values in your environment: 

    SIFT_API_KEY=paste_key_here
SIFT_PROJECT_ID=your_project_id

  2. Install the SDK.

    npm install @sift/sdk        # or: pip install sift-sdk

  3. Wrap the entry point. Everything your agent does inside the wrapper is recorded as one run. 

    import { traced } from "@sift/sdk";

export const handleTicket = traced("support-agent", async (ticket) => {
  return agent.run(ticket);
});

  4. Send a real request. The run appears in Sift within a few seconds, graded within a minute.

Runs, steps and claims

A run is one end-to-end task: a ticket answered, a meeting booked. A step is anything inside it: a model call, a tool call, a message. A claim is a statement in the run's final answer that Sift links back to the step supporting it.

A run is flagged when a claim has no support, when it uses a value a later step replaced, when an action it reports never completed, or when it loops on a tool.

Issues

Flagged runs that fail the same way, on the same tool or instruction, are grouped into one issue. An issue shows how many runs it covers, when it was first seen, and every run inside it. Close it when you ship a fix; if the failure returns, the same issue reopens with its history.

Alerts

Connect a team channel under Settings, then Alerts. Sift posts when a new issue appears and when a closed one reopens, never once per run.

Redaction

Pass field names to redact and they are removed before anything leaves your process. Redacted fields still count toward grading; their values are simply never stored.

SDK options

Option Default What it does
redact none Field names removed before sending.
sampleRate 1.0 Share of runs recorded. Keep at 1.0 unless volume forces it lower.
queueMinutes 5 How long events wait if Sift is unreachable.
