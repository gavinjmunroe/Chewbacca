Key locked decisions:

- **Split is relational vs transactional, NOT personal vs professional.** Sagar's one-liner: customer = Togari, investor = Medha. Relationship -> Medha; transaction with a sales target -> Togari; **ambiguous defaults to Medha.** Medha owns spiritual/personal/mental-health/relationship-health + the "why" behind content (Sagar's voice, Rytual brand, creative worldview). Togari owns deliverables/inbound/sales sequences. Refines [[project_medha_togari_split]].
- **One-way gate to build:** Medha can PUSH context to Togari only on explicit user ask; Togari can NEVER pull from Medha's thread. The asymmetry keeps the relationship space clean. This is the #1 inter-agent feature; generalizes to Amber multiplayer.
- **Target user:** women with complex people relationships who want help juggling networks. Emily = patient zero / constant tester (like Sagar is to Karthik).
- **Frictionless intake, no forms:** 3 paths (just talk -> silent capture; passive contacts/iMessage signal; one-question-over-time). Medha reflects categories back, user confirms; never declares "inner circle."
- **Voice (ElevenLabs) is non-negotiable** for the app to feel alive; signature feature = "older sister scrolling your contacts together" asking via voice who you're close to.
- **P0 bug:** Medha cannot decipher inbound images (Shirley sent twice, failed). Fix attachment ingestion first.
- **Brevity:** Shirley wants shorter, more concise texts; long replies read as automated/low-effort.
- Sagar also wants a team readiness/nudge engine (community yap journal -> nudge each teammate at their readiness window) + recruiting-advice consolidation, and Silo dev tasks included in the same sprint board.
