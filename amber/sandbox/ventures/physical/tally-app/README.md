# Tally

Tally turns screen time reduction into a group sport. Bet your friends, track everyone's phone usage, and win real money for actually putting your phone down.

Pre-launch waitlist landing page. Collects emails via Google Forms integration.

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```
