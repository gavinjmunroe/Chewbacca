**The thesis, standing (Caleb, 2026-10-11 3:55pm): "Make sure we stay with the thesis that chewb is an os, not an app".** Test every new piece against it before building:

- It is a system service or a surface the OS summons, never a separate app with its own window, dock icon, menu-bar identity or Login Items row. Background work registers with `chewbacca-daemon`, the OS's one system process ([[feedback_one_background_item]]).
- Things appear on the glass only while there is something on them and leave on voice, Escape or click-away. A clone of another app's window is the failure ([[feedback_hud_agents_build_on_realm]]).
- Capabilities live in the OS and every app-shaped engine is plumbing under it: wacli, gws, Realm, Anarlog are drivers, not destinations ([[feedback_everything_is_part_of_chewbacca]]).
- Success is measured as apps he stops opening (knowledgeC / `screen-time`), not features shipped.

Chewbacca OS is Caleb's goal set 2026-10-04: "I should literally need no app, just chewbacca os." Kyber (the HUD) draws glass surfaces that are walks over one local typed graph (`~/.chewbacca/os-graph.sqlite`, 0600, 7-day 80-char snippets, `kyber-surfaces forget` wipes it). Built that night on Chewbacca main: `kyber-surfaces` (needs-you, today, tasks, people, conversations, person, space), `kyber-genui` (generative panels, 14/20 first try, 19/20 after repair), `kyber-sessions` (Claude Code sessions on the glass, modeled on Carlton's desktop app), `oss-apps` (1,465 open-source app registry), glass that holds 4.5:1, token-authenticated HUD socket.

**Why:** networks other people are on (iMessage, Slack, Gmail) stay and their apps go; tools only he uses get swapped for open-source engines. Order comes from 14 days of measured app use in `docs/plans/OS-COVERAGE.md` (Chrome 15.8h, VS Code 11.7h, Messages 7.1h).

**For everyone, not just Caleb (2026-10-05):** (his words: it has to work smoothly "for literally everyone on earth") Every surface has to work for a stranger on a fresh Mac with no terminal, no Cloud Console, and no hand-edited config. What does not pass yet: Google needed a personal OAuth client in Testing mode with Caleb added as a test user by hand (project `nova-gogcli-2026`); for anyone else that is a verified OAuth app or a hosted connector. wacli needs a QR, anarlog's CLI is installed from inside its app. Each of those is an onboarding step to design, not a footnote. Gavin owns onboarding (CHW-2, CHW-11).

**Target market (2026-10-05):** Caleb: "We want the entire corporate world to get this, and then use it for the rest of their life", then "Along with the consumer world." So the bar is enterprise adoption and consumer adoption, both with lifelong retention, not a personal kit. Open gaps against that: Kyber's HUD is macOS-only Swift while most corporate desktops run Windows; local sockets without auth (the session inbox, Carlton's engine) will not pass a security review; no SSO, admin console, fleet deployment or audit log yet.

**Competitor: Ghost Core (2026-10-05).** Zain Javaid's Ghost launched Core on X on 2026-10-05 (1.35M views day one): a $3,499 box (NVIDIA RTX PRO 4000 Blackwell 24GB, Ryzen 5 7600, 64GB, 1TB) running local models (Qwen, Gemma) that pulls in email, calendar, files, wearables (Whoop, Oura, Eight Sleep) and smart home, with its own browser and file system; "no data ever leaves your home". Launch film: 2:24, one founder, one set, three demos (an elevated resting heart rate nudge, a camera reading his ingredients for an immunity shot, and "missing the GPU for Monday" to an order). Its own privacy policy carves out web search, calls, app sync, remote access and screen history through Ghost's relay, despite "no data ever leaves your home". Full teardown with Instinct, Muse, Ace and Opal: chewbacca docs/plans/COMPETITORS.md. Their launch playbook: [[reference_ghost_launch_playbook]]. Caleb: "ain't nobody tryna pay 3500 for a new computer when we make their entire software AND BETTER into mac and windows." Ghost reportedly raised $11M led by a16z, and its founder is a Z Fellows alum Caleb knows (from a 2026-10-05 conversation with Ephrem Adugna, unverified). Where Chewbacca is behind: reasoning goes to Claude in the cloud, so their privacy line is not ours yet; no wearables or smart home; Kyber is Mac-only.

**Agents from the glass (2026-10-10):** kyber-sessions is the agent cockpit. "Show my agents" (or tabs, sessions) opens it; New task + Start runs a headless `claude -p` in the background with no window; Stop ends a run the glass started plus its tool children (never a VS Code tab); `kyber-sessions watch` (launchd, every minute) toasts a tab waiting on a permission, a glass run that finished, and a tab tab-rescue found dead. A spoken "start an agent to X" only fills the New task box, because the commit review showed any audio near the mic could otherwise launch a full-permission agent. Still not possible from the glass: approving a permission prompt in a VS Code tab (Claude Code exposes no channel), and typing into an open bypassPermissions VS Code tab (held by Claude Code); Fork and send is the workaround.
