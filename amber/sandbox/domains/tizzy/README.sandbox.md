# domains/tizzy

Always-wearable autism conversation coach — product docs, Next.js demo, Expo
companion scaffold.

Folded from `amber-organization/tizzy` (`b8e19c5`). `Tizzy.ipa` excluded (rebuild
via EAS). See `.provenance.json` and repo-root `docs/`.

## Run

```bash
# Web demo
npm install && npm run dev

# Mobile
cd mobile-app && npm install --legacy-peer-deps && npm start
```
