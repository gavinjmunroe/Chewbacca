Product Engineer

Full timeNew York or remote, USEngineering

You will build the screens our customers open first thing every morning: the run viewer, the issue queue, and the alerts that pull them into both.

What you would do

  • Own the run viewer end to end, from the trace data model to the last keyboard shortcut.
  • Make a forty-step run readable in under a minute.
  • Sit in on customer calls and ship what you heard, usually the same week.
  • Write the parts of the docs that describe what you built.

What we look for

  • You have shipped a product people used daily, and you can name something about it you would change.
  • Strong TypeScript and React, and enough backend to change an API without waiting on anyone.
  • You care how a dense screen reads, not only whether it renders.

How we hire

A thirty minute call, a paid half-day project on a real problem from our queue, and a conversation with the whole team about it. We reply to every application within a week.
