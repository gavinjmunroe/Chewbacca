Data handling

  • Run data stored under AES-256, with keys rotated every 90 days
  • TLS 1.3 for every connection from the SDK
  • Each organisation's runs stored in a separate database schema
  • Field redaction in the SDK, before data leaves your process
  • Configurable retention, 30 days by default, deletion within 24 hours of request
  • Run data is never used to train models

Access

  • SSO and enforced two-factor for every employee
  • Production access reviewed quarterly
  • Support access only with your approval, logged

Operations

  • Daily backups, restore tested monthly
  • Written incident response plan
  • Dependency scanning on every build
