# Astro Overnight — Premium overnight diaper system

Astro Overnight is a pre-launch consumer product landing page for a premium overnight diaper system. The site presents three product lines: Astro Overnight Core (10-12 hour absorbency with contour-fit leg cuffs), Astro Sense (an optional smart clip that signals wet/dry state via Bluetooth without waking the room), and Astro Transition (a toddler readiness product aligned with AAP guidance). Built as a multi-section marketing site for a direct-to-consumer baby product brand.

## Features

- Multi-section landing page: Hero, Problem, Products, How It Works, Sense, Order, Footer
- Three product tiers with feature lists and availability status
- Astro Sense smart layer section with Bluetooth Low Energy technical details
- Order section for product purchase flow
- Minimal editorial design with gold accent, container layout, and custom CSS design system

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Custom CSS (editorial system with container, label, and rule classes)

## Getting Started

### Prerequisites

- Node.js 18+

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

## Deploy to Vercel

Connect the GitHub repo and deploy. No environment variables required.
